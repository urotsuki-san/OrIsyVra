# OrIsyVra 利用ガイド

通常は **Guarded Mode** を使用してください。Native Research Mode は独自構成の分析・実験用です。

## 最初に知っておくこと

OrIsyVraのGUIでは、**PNGのビジュアルキー1枚**を使います。

- PNG画像そのものが鍵です。
- 別の `.orisyvra-key` ファイルを同時に持つ必要はありません。
- パスフレーズはビジュアルキーを保護するために使います。
- パスフレーズはアプリ起動中に一度だけ入力します。
- 解除したマスターキーはメモリ内だけに置かれ、アプリ終了または「ロック」で破棄されます。
- アプリが記憶するのは、最後に選んだキーのファイルパスだけです。

## 1. ビジュアルキーを作る

1. OrIsyVraを起動します。
2. 「ビジュアルキーを作る」を押します。
3. パスフレーズを2回入力します。
4. `my-key.orisyvra-key.png` などの名前で保存します。

作成されたPNGが鍵本体です。暗号化したデータとは別の場所にもコピーを保管してください。

## 2. キーを解除する

1. 作成済みのPNGキーを選びます。
2. パスフレーズを入力します。
3. 「解除」を押します。

解除後は、アプリを閉じるまで暗号化・復号のたびにパスフレーズを入力する必要はありません。

## 3. ファイルまたはフォルダを暗号化する

1. ホーム画面で「暗号化」を選びます。
2. ファイルまたはフォルダをドラッグ＆ドロップします。
3. **Guarded（推奨）** が選ばれていることを確認します。
4. ビジュアルキーが「解除済み」になっていることを確認します。
5. 「暗号化を開始」を押します。

保存先は自動で決まります。

- ファイル: `report.pdf` → `report.pdf.orisyvra`
- フォルダ: `Documents` → `Documents_encrypted`

同名の出力がある場合は、自動的に別名へ変更します。

## 4. 復号する

1. `.orisyvra` ファイル、または暗号化済みファイルを含むフォルダを選びます。
2. 「復号」を選びます。単一の `.orisyvra` ファイルは自動判定されます。
3. ビジュアルキーを解除します。
4. 「復号を開始」を押します。

暗号化時のGuarded / Native方式はファイル内から自動判定されます。

## Guarded ModeとNative Research Mode

### Guarded

通常利用向けです。OrIsyVraの独自記録構成をXChaCha20-Poly1305で追加保護します。

### Native Research

独自構成だけを使用します。GUIでは警告への明示的な同意が必要です。重要データには使用しないでください。

## ビジュアルキーのバックアップ

「キーとバックアップ」画面から次を作成できます。

- **PNGコピー**: デジタル保管用。アプリで直接開けます。
- **印刷用PDF**: 紙で保管するための光学バックアップです。
- **回復用キー**: 同じマスターキーを別の回復用パスフレーズで保護したPNGです。

デジタルPNGには保護済み鍵データがPNG内部へ格納されています。QRコードは、印刷物やカメラ画像から復旧する場合だけ使用します。

## フォルダ処理

暗号化時は次を自動的に除外します。

- `.orisyvra` ファイル
- `.orisyvra-key` ファイル
- OrIsyVraのビジュアルキーPNG

復号時は `.orisyvra` ファイルだけを処理します。元のディレクトリ構造は維持されます。

## 暗号ドライブ（Windows alpha）

Windowsインストーラには **OrIsyVra Encrypted Volumes** も含まれます。暗号ドライブ機能には外部のWinSpdランタイムが必要ですが、通常のファイル/フォルダ暗号化には不要です。

### 新しい暗号ドライブを作る

1. 「OrIsyVra Encrypted Volumes」を起動します。
2. ビジュアルキーPNGを選択し、一度解除します。
3. 論理容量（GiB）と希望するドライブ文字を指定します。
4. 必要なら「読み取り専用」「Windowsサインイン時に自動マウント」を選びます。
5. 「暗号ドライブを作成してマウント」を押します。
6. 初回だけWindowsのディスク管理から新しいパーティションをNTFSまたはexFATでフォーマットします。
7. 以後はExplorerや通常のアプリから一般的なドライブとして利用します。

`.orisyvra-volume` はスパース方式です。たとえば論理容量100 GiBを指定しても、作成直後から物理的に100 GiBを消費するわけではなく、暗号化ブロックを書き込んだ分だけ増えていきます。

### マウントとアンマウント

登録済みドライブの「マウント」を押すと、WinSpd経由でWindowsの仮想SCSIディスクとして接続します。希望ドライブ文字が空いていれば、その文字への割当を試みます。

取り外すときは「アンマウント」を使ってください。OrIsyVraは停止要求を送り、暗号ボリュームを同期してclean状態へ更新してから切り離します。

### Windowsサインイン時の自動マウント

各ボリュームで「サインイン時に自動マウント」を選択できます。

- **通常の自動マウント（推奨）**: Windowsサインイン後にビジュアルキーを1回解除すると、そのキーを使う登録済みボリュームをまとめて開始します。
- **完全自動**: 一度解除済みのマスターキーから専用マウント資格情報を作り、そのランダムな解除情報だけを現在のWindowsユーザーのDPAPIで保護します。ビジュアルキーの元パスフレーズや生のマスターキーを平文保存しません。

完全自動は利便性と引き換えに、同じWindowsユーザー権限で動作するマルウェアに対する保護が弱くなるため明示的なオプトインです。

手動マウント用に作られる一時資格情報は5分で期限切れになり、後のWindowsサインインで再利用されません。

### 現在の制限

Windows向けのワークスペーステスト、Release build、`orisyvra-volume-gui.exe`、`orisyvra-volume-mount.exe`、Inno Setupインストーラ生成はCIで検証しています。ただし、これは多数の実機Windows/WinSpdバージョンや全アプリとの互換性を保証するものではありません。

現在も次をハードニング中です。

- UNMAP/TRIMによる認証付きブロック解放
- 書き込みキャッシュとランダムI/Oストレス試験
- sleep/resume、Windows Update、ディスクフル時の挙動
- Explorer/Office/ブラウザ/アーカイバ等の広範な実機互換性
- アイドル時間による自動ロック
- WinSpdのワンクリック導入フロー

詳細は [`VOLUME.md`](VOLUME.md) と [`WINDOWS_AUTOMOUNT.md`](WINDOWS_AUTOMOUNT.md) を参照してください。

## GUIの対応OS

ファイル/フォルダ暗号化GUIはWindows、Linux、macOS向けにビルドしています。暗号ドライブのマウント機能は現在64-bit Windows向けalphaです。
