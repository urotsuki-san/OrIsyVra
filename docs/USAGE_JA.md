# OrIsyVra 利用ガイド

通常のファイル暗号化では **Guarded Mode** を使用してください。Native Research Mode は独自構成の解析用で、具体的な安全強度はまだ設定していません。

## Windowsのキーカード

Windows版では **PNGキーカード + 4桁PIN** を使用できます。

PNGにはランダムな384-bitマスターキーを保護した鍵カプセルが入っています。4桁PINだけで鍵を保護するのではなく、Windows側で生成した256-bit端末秘密をDPAPIで保護し、PINと組み合わせて鍵カプセルを解除します。

このため、PNGだけを別のWindows PCや別ユーザーへコピーしても、端末登録がなければ解除できません。マスターキーは解除後、アプリを閉じるか「ロック」を押すまでプロセスメモリに保持されます。

旧形式のパスフレーズ式キーカードも読み込めます。

## 1. 4桁PINキーカードを作る

1. OrIsyVraを起動します。
2. 「新しいキーカード」を開きます。
3. 4桁のPINを2回入力します。
4. `my-key.orisyvra-key.png` などの名前で保存します。

PNGとWindows側の端末登録が同時に作成されます。

### コピーとバックアップ

同じWindowsユーザー上では、PNGのコピーも同じ端末登録を使用できます。

WindowsユーザープロファイルやDPAPIデータを失うと、PNGとPINだけでは復旧できません。端末故障からの復旧が必要な場合は、キーカードを解除した状態で回復用パスフレーズキーも作成し、別の場所へ保管してください。

## 2. キーカードを解除する

1. PNGキーカードを選びます。
2. PINカードなら4桁PINを入力します。
3. 旧形式のキーならパスフレーズを入力します。
4. 「解除」を押します。

解除後は「ロック」またはアプリ終了まで再入力は不要です。

## 3. ファイルまたはフォルダを暗号化する

1. ホーム画面で「暗号化」を選びます。
2. ファイルまたはフォルダをドラッグ＆ドロップします。
3. **Guarded（推奨）** を選びます。
4. キーカードを解除します。
5. 「暗号化を開始」を押します。

保存先は既存ファイルを上書きしない名前で作成されます。

- `report.pdf` → `report.pdf.orisyvra`
- `Documents` → `Documents_encrypted`

## 4. 復号する

1. `.orisyvra` ファイルまたは暗号化済みフォルダを選びます。
2. キーカードを解除します。
3. 「復号を開始」を押します。

単一の `.orisyvra` ファイルは復号として自動判定されます。Guarded / Native の判定もファイルから行います。

## Guarded Mode と Native Research Mode

### Guarded Mode

OrIsyVra Nativeの記録構成をXChaCha20-Poly1305で追加保護する通常利用向けモードです。

### Native Research Mode

OrIsyVra Native構成を直接使用する解析用モードです。

`P768/K384/C384/T256-R18` は状態、鍵、capacity、tag、round数などのパラメータを表します。384-bit securityなどの安全強度を表す名称ではありません。

## Key Sigil

PNGキーカードには、カード識別用の **Key Sigil（鍵紋章）** が表示されます。同じカードのコピーでは同じ模様になります。

Key Sigilは秘密情報でも認証タグでもありません。鍵データ本体はPNG内部のprivate chunkに保存されます。

## Windows 暗号ドライブ

メインGUIの「暗号ドライブ」から **OrIsyVra Encrypted Drives** を開けます。

### 既存ドライブへ接続

1. 対象ドライブの「接続」を押します。
2. キーがロックされている場合はPINまたはパスフレーズを入力します。
3. 必要なWindows連携設定は接続処理中に登録されます。
4. 接続後は「エクスプローラーで開く」または通常のドライブ一覧から利用します。

### 安全に切断

使用後は「安全に切断」を押します。Windows側の切断処理と暗号ボリュームの同期後に仮想ディスクを終了します。

### 新しい暗号ドライブ

1. 「＋ 新しい暗号ドライブを作成」を開きます。
2. キーカードを解除します。
3. 論理容量と希望ドライブ文字を指定します。
4. 「作成して接続」を押します。
5. 初回のみWindowsのディスク管理からNTFSまたはexFATへフォーマットします。

`.orisyvra-volume` はスパースファイルです。100 GiBの論理容量を指定しても、作成直後に100 GiBを消費するわけではありません。

### 設定と管理

各ドライブで次の項目を設定できます。

- 読み取り専用
- Windowsサインイン時に自動接続
- 完全自動（Windows DPAPI資格情報）
- backing fileの場所を開く
- 登録だけ削除

完全自動では、同じWindowsユーザー権限で動くプロセスからDPAPIを利用される可能性があるため、PIN入力を伴う接続より保護範囲が狭くなります。

WinSpdは暗号ドライブ機能の外部ランタイムとして必要です。通常のファイル暗号化には不要です。
