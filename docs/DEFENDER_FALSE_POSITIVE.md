# Microsoft Defender false positive

If Microsoft Defender Antivirus classifies an OrIsyVra Windows binary as malware, submit the exact detected file to Microsoft as a **Software developer** at:

https://www.microsoft.com/wdsi/filesubmission

Include the Defender detection name, the SHA-256 hash, the OrIsyVra release version, and the GitHub release URL.

Do not disable Defender or add global exclusions as a distribution workaround.
